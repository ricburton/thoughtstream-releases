# ThoughtStream Beta

Native Mac chat for working with Codex and Claude.

This repository hosts beta downloads, release notes, feedback and the signed update feed. Application source is maintained separately.

The first Developer ID signed and Apple-notarized beta is being prepared. There is no notarized download published here yet.

Requirements: Apple Silicon Mac, macOS 14 or later, and your own account with Codex access. Claude Code is an optional separate installation.

Once a release is published, download its ZIP, move ThoughtStream.app to Applications, and connect ChatGPT in Settings. Future betas will be available from ThoughtStream > Check for Updates. Installation always requires your approval.

Report problems through Issues. Include the app version and steps to reproduce; omit credentials and private conversations.
